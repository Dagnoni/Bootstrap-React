# Navbar com Cards Responsivos

Projeto React com navbar escura responsiva e cards em grid.

## Como rodar

```bash
npm install
npm start
```

## Características

✅ **Navbar escura** com marca e três links
✅ **Menu colapsável** no celular (< 768px)
✅ **4 cards** vindos de array via map
✅ **Key única** em cada card (`card.id`)
✅ **Altura igual** nos cards (flex: 1 no texto + marginTop: auto no botão)
✅ **Responsivo** — grid se adapta ao tamanho da tela
